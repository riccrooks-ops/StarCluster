## High-value design signals

This source is a taxonomy of FTL topologies. Its value for Star Cluster is map-generation vocabulary: gates, conduits, lanes, one-way/limited routes and unusual Precursor connections can create geography and route knowledge without replacing the accepted ordinary FTL model.
