## High-value design signals

This source is a design-method guide. It strongly supports defining FTL limits for the game experience first and then layering exceptional transit features on top. The highest-value Star Cluster application is slow/flexible ordinary FTL plus rare/generated shortcuts that even a low-TL ship can discover and exploit.
