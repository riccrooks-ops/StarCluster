# Checkpoint 125 — Pure-TL Whole-Ladder Integrated Progression Study

## Intent

CP125 uses the accepted CP123 numerical baseline and CP124 executable/instrumentation foundation for the first large integrated TL1-TL9 combat study. Each ship uses components from one TL only; opponents may be any TL. Mixed-TL ships are explicitly deferred.

## Required acceptance evidence

Repository/native acceptance must prove:

- accepted CP124 provenance and frozen CP122/CP123 implementation/reference authorities;
- 152/152 Python tests;
- 25/25 existing research parity fixtures;
- exact reuse of the 9,427-build CP124 legal universe;
- exact 44,429,451 canonical legal-pair population reconstruction;
- 45 canonical TL cells / 81 ordered TL cells;
- 70,034 deterministic weighted base pairings;
- 84,843 build/opponent-TL coverage relationships with no missing legal build in any TL relationship;
- 280,136 side/movement symmetry variants;
- one-trial full-pipeline smoke: 280,136/280,136 executions, zero trial errors;
- normal run: 56,027,200 substantive engagements, zero trial errors, all 81 ordered TL cells;
- 47-metric CP124 telemetry authority retained;
- no mixed-TL ship construction and no automatic numerical promotion.

## Balance boundary

Win-rate, dominance, Delta-TL, family, power, EW, PDS and movement-order findings are review evidence. They are deliberately non-blocking. CP125 fails for broken population accounting, missing variants/cells, instrumentation/execution errors or provenance drift—not because a technology generation wins “too much” or “too little.”

## Consumer limits

CP124 research-consumer limits remain explicit: internal critical/subsystem damage is absent, Python Missile travel is not full C# moving-target/range-exhaustion parity, Damage Control is not scheduled into combat, and mission/AUX fill remains zero-effect capacity.

## Authoring validation before native handoff

The packaged candidate is required to pass deterministic authoring checks before native Windows acceptance:

- full Python regression suite: 152/152;
- existing research parity fixtures: 25/25;
- complete pairing-plan reconstruction: 9,427 legal builds, 70,034 base pairings, 280,136 symmetry variants, 84,843 build/opponent-TL coverage relationships, and 56,027,200 planned substantive engagements;
- representative execution probe: one canonical base pairing from each of the 45 unordered TL cells, expanded through all four side/movement mirrors (180 trials), observing all 81 ordered TL cells with zero trial errors.

The representative authoring execution probe is **not** a substitute for the native full-pipeline smoke. The complete 280,136-variant one-trial smoke and 56,027,200-engagement substantive run remain mandatory native gates because the authoring container has constrained multiprocessing/CPU capacity compared with the target Windows workstation. No authoring mini-smoke outcome is balance evidence.
