# Checkpoint 164 — Final Isolated Power Economy Closure Sweep

CP163 native acceptance selected a strong provisional APU trajectory: **2 Space**, **+1 Operational TP at TL1–4**, **+2 Operational TP at TL5–9**, with unrestricted installation counts bounded by Space economics and with +3 TP rejected as a normal maturation step. CP164 is intentionally the **last isolated power-only sweep** before whole-system integration.

## Frozen inputs

- CP160-PF4 remains the pending-finalization research baseline.
- Main Reactor footprint remains **6 Space at every TL**.
- Main Reactor Operational output is tested only at **PF4 −1 / PF4 / PF4 +1 TP**, independently at every TL.
- APU footprint is fixed at **2 Space**.
- APU output is fixed at **+1 TP TL1–4 / +2 TP TL5–9**.
- No APU installation-count cap is imposed; 0/1/2/3/MAX stack tiers remain explicit.
- Production numerical authority, Concept, subsystem TP costs, and all non-power combat values are frozen.

## New attribution question

CP161–163 primarily asked how ships respond to a given supply level or to adding an APU. CP164 directly measures the **marginal value of one additional Main-Reactor TP** at each TL while holding ship architecture and APU stack constant.

The direct combat layer uses a common PF4−1 matrix and research-only per-build additive TP of 0/1/2 to represent PF4−1/PF4/PF4+1 for one-Reactor carriers. This makes the two sides mechanically identical except for the tested one-TP Main-Reactor increment and any identical APU stack already installed. It is Operational-power attribution only; it does not change production mechanics or claim to model reactor damage states.

## Study scale

- 22,482 legal powered architectures retained as the reference population.
- 16,741 one-Main-Reactor architectures used for closure attribution.
- 5 stack tiers: 0 / 1 / 2 / 3 / MAX.
- 3 Main-Reactor candidates per TL: PF4−1 / PF4 / PF4+1.
- 6 stochastic doctrines.
- 810 stochastic variants × 5,000 turns = **4,050,000 tactical-demand samples**.
- 90 direct mirrored combat contexts per TL = 810 cells total.
- 2,000 trials/cell = **1,620,000 substantive combats**.

## Interpretation boundary

There is no automatic tuning or promotion. CP164 should answer whether the PF4 Main-Reactor value at each TL should remain, move down one TP, or move up one TP when considered alongside the selected APU. After CP164 assessment, **isolated Reactor/APU output calibration closes** and the next substantive checkpoint moves to whole-system integration, including damage-state and repair interactions.
