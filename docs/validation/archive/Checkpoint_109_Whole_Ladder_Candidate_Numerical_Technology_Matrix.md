# Checkpoint 109 - Whole-Ladder Candidate Numerical Technology Matrix

## Purpose
Checkpoint 109 builds the first complete candidate numerical TL1-TL9 technology/component matrix after the Technology Family Storyboard and CP108 qualitative review. The checkpoint deliberately builds the whole candidate surface before balance calibration.

## Accepted baseline
Checkpoint 108 is the native-accepted qualitative technology-architecture baseline: 10 disciplines, 32 source lineages, 214 Storyboard beats, 136 ideas, 20 foundation domains, 35 support candidates, zero trials, and no TL4-TL9 numerical values.

## CP109 outcomes
- 16 core numerical profile families x 9 TLs = 144 profile rows.
- 31 explicit numerical branch/specialist candidates.
- 16 sparse causal hard-prerequisite candidates; only four are normal-spine gates.
- Automatic unlock when owning TL and final external prerequisite are complete; no second project/cost.
- TL1-TL3 values are historical evidence/runtime seeds rather than immutable progression locks.
- Uneven technological jumps, quiet TLs, family handoffs, and maturation through Space/efficiency/resilience/modes are valid.
- Whole-ship Space sanity is calculated for all nine TLs but is not a balance claim.

## Calibration boundary
No combat calibration, Monte Carlo, research-engine study, Deep Calibration, or numerical promotion occurs in CP109. Existing C#/Godot production data and existing simulation/test code remain frozen. The candidate matrix is an input for later controlled subsystem and integration calibration.
