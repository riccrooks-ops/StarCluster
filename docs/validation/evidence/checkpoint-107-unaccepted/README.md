# Checkpoint 107 Unaccepted Candidate Evidence

Checkpoint 107 did not reach native acceptance. Its architecture/design artifacts are preserved and carried unchanged by Checkpoint 107a, but its PowerShell contract used one-letter helper function names that collided case-insensitively with built-in Windows PowerShell aliases (`h` / `Get-History`, `r` / `Invoke-History`).

`CHECKPOINT_107_SHA256SUMS.txt` is the exact manifest from the failed CP107 candidate and is retained only as provenance evidence. CP107a is the active acceptance path.
