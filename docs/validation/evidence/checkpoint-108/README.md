# Checkpoint 108 Evidence

This directory preserves the deterministic architecture evidence for the CP108 candidate.

- `CP107B_FROZEN_NUMERICAL_EXECUTABLE_SHA256SUMS.txt` freezes the 133 numerical/executable files that CP108 is not permitted to change.
- `cp108-qualitative-architecture-evidence.json` records the intended qualitative corrections, counts, runtime/testing boundary, and authoring QA state.

CP108 remains a candidate until both native Windows launcher paths succeed. Native acceptance output should be captured here by the next accepted checkpoint or acceptance-evidence pass rather than fabricating a local native result.
