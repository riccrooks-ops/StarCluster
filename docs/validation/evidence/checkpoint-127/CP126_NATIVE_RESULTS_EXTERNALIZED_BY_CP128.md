# CP126 native results externalized by Checkpoint 128

The accepted CP126 native-results archive was intentionally removed from successor full-repository packaging by CP128 to prevent repeated nesting of large raw Monte Carlo outputs. Its accepted SHA-256 remains `a82e8e1f98f9af5589666d091f4773cd3f98b881c82c108a7da7ab2d1c74edb0`.

CP128 preserves a full per-entry SHA-256 content manifest and a curated set of acceptance/summary artifacts under `docs/validation/evidence/checkpoint-128/curated-predecessor-native-evidence/cp126/`. Historical CP127 scripts remain byte-frozen and therefore still name the original archive path; rerunning that historical checkpoint from a later repository requires supplying the original accepted results archive separately.
