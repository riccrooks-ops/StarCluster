# CP125 native results externalized by Checkpoint 128

The accepted CP125 native-results archive was intentionally removed from successor full-repository packaging by CP128 to prevent repeated nesting of large raw Monte Carlo outputs. Its accepted SHA-256 remains `e26f4a79075cd3bb395213d9a4da7d9e3708fecd3dbd3b5a29911c24ea63ecf0`.

CP128 preserves a full per-entry SHA-256 content manifest and a curated set of acceptance/summary artifacts under `docs/validation/evidence/checkpoint-128/curated-predecessor-native-evidence/cp125/`. Historical CP126 scripts remain byte-frozen and therefore still name the original archive path; rerunning that historical checkpoint from a later repository requires supplying the original accepted results archive separately.
