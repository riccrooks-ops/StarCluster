# Checkpoint 84 Validation Tiers

Checkpoint 84 remains a **must-always-run** acceptance checkpoint because it changes the active standing Technology Integration Permutation Suite and the integrated ScenarioRunner consumer used for Shield/Power calibration.

## Normal acceptance

The normal path runs 11 stages. It preserves the deterministic/core-regression front of the current suite, performs an actual-consumer preflight for the 216-variant CP84 study, executes one trial for every variant as a full-pipeline smoke, then runs the 216 variants at the requested substantive trial count. At the default 10,000 trials this is 2,160,000 substantive trials plus 216 smoke trials.

Release gates are mechanical/configuration invariants. They prove the complete Shield 2/3/4 x Reactor 5/6 factorial, the Shield-capacity-only change, the carried-forward CP83 reactor value, clean Firm and contemporary DR1+ECCM1 information-control paths, stateful recharge consumer routing, and the absence of bundled hardening/recharge/overload/production changes. Outcome and balance observations remain review-only.

## Deep Calibration

Deep Calibration is optional and is not required merely because CP84 changes a new progression axis. It retains the broader historical calibration corpus and substitutes CP84 for CP83 as the current primary study. Use it only when a later dependency change or explicit cross-system question justifies the additional cost.
