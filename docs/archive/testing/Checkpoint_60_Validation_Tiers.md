# Checkpoint 60 Validation Tiers

Checkpoint 60 keeps the Checkpoint 59 test-suite scrub and adds the current 35-Space deterministic construction envelope to the **must-always-run** tier.

## Must always run

The default checkpoint proves repository integrity, the pinned warnings-as-errors build, xUnit/Core mechanics, deterministic missile and TL1 combat contracts, finite-resource semantics, ScenarioRunner self-tests, and the new 35-Space construction/combinatorial envelope.

The construction stage has **27 legal macro loadouts** and **96 weapon/power variants**. It is deterministic and adds no Monte Carlo trials to the default release path.

## Deep Calibration

`-DeepCalibration` keeps the default tier and adds the same twelve retained TL1 stochastic studies accepted under Checkpoint 59: **1,026 variants / 10.26 million trials** at the normal 10,000-trial setting.

Run Deep Calibration when a change can plausibly affect those combat-mechanics dependencies or when broader regression evidence is explicitly desired. It is not required merely because a new checkpoint exists.

## Historical-only studies

The 38 superseded Checkpoint 58e stages remain historical evidence and are not restored to the active release lineup. Their old Weapon Bay/AUX-capacity, single-main, TL1/4/7 generation, or fixed screening-target assumptions are not current design contracts.

## Next tier to add

The next simulation pass should use the deterministic envelope to select a **small composed-ship Monte Carlo matrix** containing both normal reference ships and deliberately odd legal builds. That study should diagnose power starvation/surplus, attack-package density, PDS concentration, defense opportunity cost, pacing, and matchup sensitivity without imposing predetermined win percentages.
