# Checkpoint 87 Validation Tiers

## Must always run

Checkpoint 87 validates the first generated cross-TL legal-build/permutation pipeline. The normal native pass must run:

- repository manifest and native-dependency contracts;
- warning-as-error build and the full unit-test project;
- retained deterministic mechanics, TL1 Phase A/B, the 35-Space construction envelope, and the Sensor/EW foundation;
- native cross-TL generator preflight;
- native generation of the legal-build catalog and generated integrated-combat study;
- actual-consumer preflight of that generated study;
- a one-trial-per-variant full-pipeline smoke across all 192 generated variants;
- the 192-variant substantive cross-TL representative screen;
- retained finite-resource/damage-state semantics; and
- all ScenarioRunner self-tests.

The generated-study chain is a release requirement. Static JSON generation alone is insufficient.

## Deterministic enumeration scope

The foundation has eight independent axes: one four-choice weapon axis plus seven binary TL1/TL2 axes. It must enumerate exactly **512 legal builds** in the declared 35-Space exact-fill shell. The complete pairing envelope is recorded deterministically; only the declared representative recipe/pairing slice proceeds to Monte Carlo.

Power overcommit is not a construction-illegality filter. The enumerator must retain legal mixed-generation and strategically awkward builds whenever they satisfy the actual construction constraints represented by the foundation.

## Combat-activity quality gate

Every logical pairing has a fixed Range-3 reference plus two TrackAware dynamic movement-order contexts. If the fixed reference materially uses direct fire or launches missiles, each paired dynamic context must preserve nonzero activity for that attack type unless a future study explicitly declares a no-fire/search/withdrawal control.

This gate exists to prevent movement doctrine from creating false balance evidence by moving outside its own usable targeting/guidance envelope.

## Deep Calibration

Deep Calibration is optional and dependency-driven. CP87 Deep Calibration adds the accepted CP86a 288-variant weapon-penetration regression to the normal generated cross-TL pipeline. Do not run it by default unless native results expose an uncertain interaction or a changed dependency justifies the extra historical stochastic work.

## Release interpretation

Green execution validates enumeration, generated-study routing, attack-activity integrity, and the bounded cross-TL screen. Win rates, rankings, complete-TL deltas, mixed-build performance, and progression shape remain human-review evidence. CP87 automatically promotes no component or technology value.
