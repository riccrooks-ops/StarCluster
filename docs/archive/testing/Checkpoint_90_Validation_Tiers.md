# Checkpoint 90 Validation Tiers

Checkpoint 90 expands cross-TL construction/permutation infrastructure. It changes generated-study architecture and runtime handling of redundant EW installations, but it does not retune accepted technology values.

## Must always run

- Repository/manifest and accepted-CP89 provenance contracts.
- Warning-as-error native build and full unit-test project.
- Accepted deterministic mechanics stages.
- Generalized legal-build preflight: 82,944 raw combinations, 22,592 legal builds, 4,672 exact-fill builds, and mandatory Main Weapon/Reactor core.
- Generated-study actual-consumer preflight.
- One-trial-per-variant full-pipeline smoke for all 432 generated variants.
- 432-variant / 4,320,000-trial generalized cross-TL screen at the normal 10,000 trials per variant.
- Fixed-reference power-doctrine viability, dynamic activity preservation, rated-cost EW doctrine, and non-additive EW redundancy gates.
- ScenarioRunner self-tests, including generalized Cartesian accounting and highest-functional EW redundancy behavior.

## Deep Calibration

Deep Calibration is optional and dependency-driven. It adds the accepted CP86a 288-variant weapon-penetration regression at full trial count. Do not run it merely because Checkpoint 90 changes enumeration architecture. Run it only if native results indicate a penetration/damage interaction requiring revalidation or a declared dependency of that study changed.

No win-rate target is a release gate. Build rankings, progression strata, and cross-TL outcome spreads remain human-review diagnostic evidence.
