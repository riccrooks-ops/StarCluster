# Checkpoint 101 Validation Tiers

## Must-always-run native acceptance

CP101 is a technology/data/documentation architecture checkpoint. Native acceptance must run the warning-as-error build, 876 xUnit tests, retained deterministic/mechanics stages, CP99 v0.8 preflight/generation, resource-semantics locks, and 63 ScenarioRunner self-tests.

## Substantive Monte Carlo

**Not applicable.** CP101 completes the conceptual TL3 base table but leaves `tl3CombatConsumerEnabled=false`. No new TL3 combat value is calibrated or promoted by this checkpoint.

## Deep Calibration

Not applicable. A later checkpoint that implements the TL3 consumer must add actual-consumer preflight and a tiny full-pipeline smoke before any substantive cross-TL Monte Carlo.
