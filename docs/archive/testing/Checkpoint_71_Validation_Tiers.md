# Checkpoint 71 Validation Tiers

## Must always run

Checkpoint 71 keeps the accepted layered release structure:

1. repository manifest, native-dependency, and PowerShell syntax checks;
2. pinned .NET SDK warning-as-error build and engine-independent tests;
3. accepted deterministic missile and TL1 mechanics/direct-fire corpora;
4. current 35-Space construction/resource regressions;
5. the 924-row CP71 deterministic Sensor/EW discrimination/burn-through sweep;
6. the actual-consumer 27-variant CP71 integrated-loader preflight;
7. a 27-variant, one-trial-per-variant full-pipeline smoke;
8. only then the 27-variant / 270,000-trial substantive burn-through study;
9. retained resource/endurance locks and ScenarioRunner self-tests.

The smoke and substantive stages are both non-blocking on target win rates, but all structural, telemetry, no-error, point-blank geometry, and burn-through semantic gates are blocking.

## Deep Calibration

Deep Calibration remains optional unless the normal suite exposes an interacting regression or the current design question requires broader calibration. Historical studies whose assumptions have been superseded remain archived evidence rather than mandatory active gates.

## Study boundary

CP71 changes the discrimination stage only. It does not promote a sensor range candidate, change ECM/ECCM power cost, implement degraded fire, change weapon power, or alter missile guidance/seeker rules.
