# Checkpoint 93 Validation Tiers

Checkpoint 93 is the first substantive simulation pass after the CP91-CP92 reference-mining excursion. It resumes the CP90a generalized legal-build program without changing accepted gameplay values. Its purpose is to harden **how** the 22,592-build cross-TL envelope is analyzed before any wider sampling or new component tuning.

## Must always run

- Native/archive pre-check, including the proven direct named-parameter checkpoint-wrapper call into `run_calibration_checkpoint.ps1`; splatted/positional wrapper forwarding remains rejected before harness execution.
- Repository/manifest contract and exact accepted-CP92 provenance binding.
- Warning-as-error native build and full unit-test project.
- Accepted deterministic mechanics stages.
- ScenarioRunner self-tests (**57 expected**, adding one deterministic CP93 strata/envelope test to the accepted 56).
- Deterministic cross-TL v0.4 generator preflight over the unchanged 82,944 raw / 22,592 legal build envelope.
- Exact Space-utilization accounting: 4,672 exact-fill, 11,328 near-fill, and 6,592 underfilled legal builds.
- Exact distinct-pair arithmetic: 255,187,936 unordered distinct / 510,375,872 oriented distinct legal pairs.
- Complete 96-cell population accounting across composition x orientation-neutral progression magnitude x Space-pair stratum.
- Deterministic matched sampling of one unordered distinct base pair per cell and both A/B orientations: 96 base pairs -> 192 stratified logical pairings; plus 48 named diagnostics -> 240 logical pairings.
- Three geometries per logical pairing -> **720 generated variants**.
- Actual-consumer preflight of the generated study.
- One-trial full-pipeline smoke over all 720 generated variants before substantive Monte Carlo.
- Bounded substantive study at **2,000 trials per variant by default** -> 1,440,000 primary trials.
- Side-specific direct-fire/missile activity telemetry must sum to the accepted aggregate counters.
- Contextual activity gates must reject nominally `reference_ready`/`closing_ready` family lanes that produce no appropriate attacks, while permitting structurally `engagement_denied` all-legal variants.
- Report routing for matched pair/orientation analysis, raw and population-weighted screening, all-legal versus mutually active cohorts, Space comparability, weapon-family pairing, information-control gap, and reproducible pair/population manifests.
- Frozen CP92 reference-mining corpus and accepted gameplay/technology authorities except for the explicitly permitted simulation-analysis files.

## Primary bounded study

The CP93 Monte Carlo study is a required architecture-proving screen, not a balance-calibration promotion gate. It deliberately uses 2,000 trials per variant so the new classification, matching, weighting, and activity guards can be reviewed before the sample or trial count is widened.

Win rates, higher-advanced-side conditional results, population-weighted aggregates, orientation gaps, readiness cohorts, and Space strata are **review-only evidence**. No outcome threshold promotes, demotes, or retunes a component automatically.

## Deep Calibration

Deep Calibration is **not applicable** to Checkpoint 93. `-DeepCalibration` intentionally aliases the same bounded CP93 workload. A larger cross-TL sample or higher-trial escalation belongs in a later checkpoint after CP93's native evidence demonstrates that the analysis architecture is sound.

## Acceptance boundary

A green CP93 run proves that the current legal-build envelope can be classified, matched, sampled, consumed, gated, and reported under the new v0.10 analysis architecture. It does **not** establish that every sampled progression is balanced, that one pair represents all builds in its population cell, or that any candidate technology is ready for production promotion.
