# Checkpoint 85 Validation Tiers

Checkpoint 85 remains a **must-always-run** acceptance checkpoint because it changes the active standing Technology Integration Permutation Suite and the integrated ScenarioRunner consumer used for Armor / Shield calibration.

## Normal acceptance

The normal path runs 11 stages. It preserves the deterministic/core-regression front of the current suite, performs an actual-consumer preflight for the 288-variant CP85 study, executes one trial for every variant as a full-pipeline smoke, then runs the 288 variants at the requested substantive trial count. At the default 10,000 trials this is 2,880,000 substantive trials plus 288 smoke trials.

Release gates are mechanical/configuration invariants. They prove the complete Shield 2/3 x Armor AP/AI factorial, independent AP and AI overrides, the carried-forward 6-TP reactor and Shield-3 working candidates, current weapon APEN references, clean Firm and contemporary DR1+ECCM1 information-control paths, stateful shield-recharge routing, and the absence of bundled armor, shield, reactor, or production changes. Outcome and balance observations remain review-only.

## Deep Calibration

Deep Calibration is optional and is not required merely because CP85 adds Armor as a progression axis. It retains the broader historical calibration corpus and substitutes CP85 for CP84 as the current primary study. Use it only when a later dependency change or explicit cross-system question justifies the additional cost.
