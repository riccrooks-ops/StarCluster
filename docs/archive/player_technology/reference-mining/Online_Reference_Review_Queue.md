# Online Reference Review Queue

## Purpose and originality boundary

These sources are potential comparative references for gameplay questions, naming patterns, subsystem relationships, progression, interface clarity, campaign pressure, and implementation concepts. They are not specifications. Star Cluster must not copy proprietary prose, art, distinctive names, exact technology ladders, numerical tables, formulas, events, combat matrices, or another game's defining core mechanics.

The Concept and Decision Register remain authoritative. Any adopted lesson must be restated as an original Star Cluster proposal and tested against KISS, the single-ship campaign, observer-safe information, and the intended fantastical space-opera tone.

## Review output

For each source actually reviewed, record:

- the design question examined;
- a paraphrased observation;
- a possible original Star Cluster application;
- KISS and complexity risks;
- adoption status: adopted, adapted, deferred, rejected, or background only;
- any related component family or stable decision ID.
