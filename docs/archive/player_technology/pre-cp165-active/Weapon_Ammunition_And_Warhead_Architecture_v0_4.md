# Weapon, Ammunition, and Missile-Family Architecture v0.4

**Checkpoint:** 123  
**Status:** revised reference architecture; no balance calibration

## Family boundary

Normal Kinetic ammunition auto-matures on compatible accelerators when the improvement is a strict upgrade. The TL4 Maneuvering / Programmable Smart Projectile is therefore represented by the Kinetic reference profile's +5 pp ACC maturation rather than a routine per-shot ammunition menu.

Missile technology is separated into **delivery/propulsion**, **guidance/seeker**, **general-purpose warhead yield**, and **Swarmer Flight** characteristics. A Missile Flight remains one counter and one attack package.

## General-purpose warhead reference

- TL1-2: D10 / SPEN2 / APEN4 fission-era GP.
- TL3-4: D11 / SPEN2 / APEN4 mature fission GP.
- TL5-6: D13 / SPEN2 / APEN4 Fusion GP; Power TL2 prerequisite.
- TL7-9: D15 / SPEN2 / APEN4 Antimatter GP; Power TL5 prerequisite.

Yield does not automatically add penetration. These values are the CP123 baseline to test.

## Swarmer Flight reference

Swarmer becomes a distinct selectable Flight family at TL2. It keeps one Flight counter, one terminal attack roll, the ordinary Firm-terminal requirement, generic Missile Flight inventory, and no extra PDS windows or critical rolls. The two internal packets mature D4 → D5 → D7 → D8 at TL2/TL3/TL5/TL7; coverage/guidance is +10 pp until TL7 and +15 pp thereafter, while PDS interception receives a bounded -10/-15 pp modifier. Swarmer has SPEN0/APEN0 in this reference baseline.

Specialist shaped, shield-disruption, radiation, matter-conversion and other warheads remain deferred unless later gameplay testing justifies the extra choice.
