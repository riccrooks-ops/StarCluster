# Technology Component Table v0.4

**Checkpoint:** 117  
**Status:** Weapon-family simplification architecture; no balance calibration

Carry CP108 qualitative architecture forward while reconciling Kinetic ammunition and Missile warhead player expression, compatibility, generic magazine accounting and observer-safe combat feedback per CP113.

## CP117 weapon-family simplification rules

- Energy retains a small set of meaningful power/output modes.
- Normal Kinetic projectile improvements auto-mature; no routine per-shot ammunition selector.
- Missile GP yield matures automatically at major energetic milestones; yield does not automatically add SPEN/APEN.
- Swarmer Missile is a distinct TL5-TL7 Flight-family branch emphasizing coverage/PDS saturation at lower concentrated packet strength.
- Shaped/anti-Shield specialist warheads remain preserved concepts but are deferred from the assumed normal baseline menu.
- TL1-TL6 drive calibration; TL7 is advanced validation; TL8-TL9 are endpoint stress checks.
