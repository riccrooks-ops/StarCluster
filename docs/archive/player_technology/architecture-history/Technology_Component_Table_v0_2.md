# Qualitatively Reviewed TL1-TL9 Technology / Component Table v0.2

**Checkpoint:** 108  
**Status:** Architecture candidate after qualitative review; no balance calibration or numerical TL4-TL9 promotion

Review and refine CP107b whole-ladder technology placement, naming, player-facing expression and branch/default ownership before any TL4-TL9 numerical calibration.

## Architecture guardrails

- Ten visible research disciplines remain independent; each retains useful native progression without generic breadth gates.
- Quiet primary-family TLs are legal. A branch unlock does not become the default family merely because the primary lineage is quiet at that TL.
- Every Storyboard beat has an explicit player-expression class. Not every research beat becomes a separate component.
- Related research remains descriptive and non-gating. CP108 promotes **zero** hard external prerequisites.
- Causal/precognitive information remains Precursor-only; normal TL9 information systems are powerful but probabilistic and observer-safe.
- Auxiliary/support uses universal Installation Space and the gameplay-loop KISS rule.
- Starting cruiser remains one shuttle; Fuel remains 100 / 2 per traversed hex / +1 per EvM turn; TL1 Ablative Armor remains 1 Space.
- C# / Godot remains the production game runtime. Python is permitted for simulation, testing, analysis, and checkpoint validation but is not a shipped game-runtime dependency.
