# Provisional TL1-TL9 Technology / Component Table v0.1

**Checkpoint:** 107  
**Status:** Architecture candidate; no balance calibration or numerical promotion

This is the first explicit translation of the accepted Technology Family Storyboard into a player-facing TL1-TL9 technology/component map. It does **not** make every story beat a production component, and it does not assign new TL4-TL9 numbers. Existing TL1-TL3 numerical authority remains where it already lives.

## Architecture guardrails

- Ten visible research disciplines remain independent. Each owns a useful vertical spine.
- Blank/quiet family TLs are legal; no filler upgrade is invented merely to populate a cell.
- Related research is informative and non-gating. CP107 promotes **zero** hard external prerequisites.
- Later hard prerequisites should be sparse, component-specific, and genuinely causal; they may not turn broad research into a blanket gate on a normal vertical spine.
- Auxiliary/support is a role, not a separate slot currency. Every installed item uses the universal Installation Space budget.
- Support/AUX KISS rule: **an optional support component belongs only when it materially changes capability, risk, or efficiency in an existing gameplay loop.**
- Starting cruiser: **one shuttle**. Current tactical Fuel working scale: **100 Fuel; 2 per traversed hex; +1 Fuel/turn for EvM**. TL1 Ablative Armor: **1 Space**.

## Reference and design reconciliation

- CP105 reference synthesis remains the design-pattern source: family-specific progression, overlapping generations, specialist branches, legacy revivals, storage separate from generation, and bounded high-SF transitions.
- CP106 observation coverage remains closed at 195/195 observations; CP107 consumes that architecture rather than reopening broad reference mining.
- The CP43 Auxiliary Capacity catalog is superseded as design authority and archived, but an unchanged legacy-path copy is retained because frozen runtime/calibration consumers still reference it. Its separate slot pool and several old TL floors must not be treated as current architecture.
- Mission/support concepts (Medical Bay, Fuel Processor, Fabricator, Laboratory, mining, cargo, magazines, communications, mission package, and Hangar/Mission Bay) are retained because each connects to an explicit gameplay loop.
